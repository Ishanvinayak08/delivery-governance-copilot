# Changelog

All notable changes follow [Keep a Changelog](https://keepachangelog.com/) and semantic versioning.

## [0.1.0] - 2026-11-04
### Added
- Ingestion of meeting notes, emails and Jira CSV exports.
- Offline RAID extraction and optional schema-validated LLM extraction with PII redaction.
- Seven configurable governance rules (GOV-001 to GOV-007) and RAG scoring.
- Draft weekly report, RAID log CSV, findings JSON and append-only audit log.
- Project governance documents, ADRs, CI and GitHub templates.
