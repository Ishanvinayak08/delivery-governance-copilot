# RACI

R = Responsible, A = Accountable, C = Consulted, I = Informed.

| Activity | Maintainer / PM | Reviewer | Users / interviewers |
|---|---|---|---|
| Charter and scope | A/R | C | I |
| Governance rules and policy | A/R | C | C |
| Implementation | R | C | I |
| Code review | I | A/R | I |
| Testing and sample data | R | C | I |
| Release and changelog | A/R | C | I |
| Risk and issue management | A/R | C | I |

Note: this is a solo-maintained portfolio project. The Reviewer role is filled by an invited peer or by CI plus a self-review checklist until a second contributor joins (see RAID R-02).
